# Tasks and Subagents Implementation Plan

> Execute the approved complete feature in this session, with tests and independent review; do not pause between components.

**Goal:** Background terminals and child Pi agents with shared task list, live searchable log viewer, per-task cancellation, completion delivery and retained logs.

**Architecture:** A session-scoped TaskManager owns child processes and bounded output. Separate terminal and Pi JSON adapters feed the same task registry. A keyboard-driven overlay and above-editor widget expose that registry; four namespaced tools expose it to the model. Child Pi processes inherit the user's provider configuration, model and thinking level, but do not register recursive pi-ter task tools.

**Tech Stack:** TypeScript, Node child_process, Pi 0.85.1 extension API and pi-tui. No new runtime dependencies.

**Spec:** User-approved feature list in this conversation: complete terminal + subagent + viewer + stop + completion; keep existing header/editor/status bar.

## Global Constraints
- Windows and POSIX process-tree cancellation, never global agent abort for an individual task.
- Closing viewer does not stop tasks. Closing/switching Pi session stops owned tasks.
- Display terminal stdout/stderr and emitted agent messages/tool events; do not fabricate progress.
- Bounded memory and persisted logs with explicit truncation notices. No arbitrary PID kill or cross-session task mutation.
- Namespace commands and tools under piter; /tasks is the convenient alias. Shortcut Ctrl+Alt+T.
- Default concurrency 4; default timeout 30 minutes, explicit 0 for no timeout. Model inherits parent provider/id.
- No terminal-emulator input/PTY claim: captured-output viewer, not interactive stdin attachment.
